## 2. Brand Identity

### Mission
**Démocratiser l'éducation de qualité en Afrique via la technologie**

### Vision
**Chaque école africaine bénéficie d'outils numériques modernes, accessibles et abordables**

### Values
- 🌍 **Inclusivité** : Accessible à tous, peu importe le pays ou la bande passante
- 💡 **Innovation** : Solutions pédagogiques avant-gardistes
- 🤝 **Collaboration** : Écoles, enseignants, élèves, parents connectés
- 📊 **Data-driven** : Décisions basées sur les datos
- ♻️ **Durabilité** : Infrastructure éco-responsable

## 11. Animations

### Transitions
```
Duration:   150ms / 200ms / 300ms
Easing:     ease-in-out
Property:   opacity, transform, color, background

Examples:
  Button hover:   150ms ease-in-out on opacity + transform
  Modal open:     300ms ease-in-out (scale 0.95 → 1)
  Loading:        Linear infinite rotation (1s)
```

### Micro-interactions
```
Button press:         Scale 0.98
Checkbox check:       Scale 1.1 + fade
Switch toggle:        Slide 200ms
Dropdown open:        Fade in 150ms + slide down
Hover elevation:      Change shadow 200ms
```

## 12. Responsive Design

### Mobile-First Approach
```
Mobile (< 768px):
  - Single column layout
  - Full-width cards
  - Bottom tab navigation
  - Touch targets: 44x44px minimum
  - Font sizes: 14-16px body

Tablet (768px - 1024px):
  - 2-3 column layout
  - Drawer navigation
  - Larger spacing
  
Desktop (> 1024px):
  - Multi-column
  - Sidebar navigation
  - Optimized for 1920px+
```

## 14. Accessibility

### WCAG 2.1 AA Compliance

```
✓ Color Contrast: 4.5:1 for text, 3:1 for graphics
✓ Focus Indicators: Visible 2px outline
✓ Keyboard Navigation: All interactive elements accessible
✓ Alt Text: All images >= 125 chars
✓ Semantic HTML: Proper heading hierarchy
✓ Screen Reader: ARIA labels where needed
✓ Resize Text: Support up to 200%
✓ Motion: Respect prefers-reduced-motion
```

### Checklist
- [ ] Color not only indicator (icons + text)
- [ ] Sufficient contrast ratios
- [ ] Focus visible on all buttons/inputs
- [ ] Keyboard accessible forms
- [ ] Video with captions
- [ ] Readable font sizes (min 14px)

## 15. Usage Guidelines

### Do's ✓
```
✓ Use Violet-800 for primary CTAs
✓ Use Ambre for important alerts
✓ Maintain consistent spacing
✓ Use Inter for all text
✓ Keep 2-3 colors per view
✓ Respect user preferences
✓ Test accessibility
```

### Don'ts ✗
```
✗ Mix color systems
✗ Use too many typefaces
✗ Stack colors without contrast
✗ Ignore dark mode users
✗ Use auto-playing media
✗ Remove focus indicators
✗ Tiny click targets (< 44px)
```

## 16. Asset Delivery

### File Formats
```
Logos:
  • PNG (transparent bg)
  • SVG (scalable, preferred)
  • PDF (print)

Icons:
  • SVG (web, all sizes)
  • PNG (raster fallback)

Images:
  • WebP (modern browsers)
  • JPEG (fallback)
  • PNG (when transparency needed)

Compression:
  • Images: ImageOptim / TinyPNG
  • SVG: SVGO
  • CSS: cssnano
```

### Performance Targets
```
Logo load:        < 5KB
Icon sprite:      < 10KB
Page images:      < 50KB per image
CSS total:        < 50KB (minified)
```

## 17. Brand Tone & Voice

### Tone
- Friendly & Approachable
- Professional & Trustworthy
- Clear & Concise
- Encouraging & Supportive

### Vocabulary
```
Use:
  - "Create" instead of "make"
  - "Connect" instead of "link"
  - "Explore" instead of "browse"

Avoid:
  - Corporate jargon
  - Overly technical terms
  - Negative language
```

### Example Microcopy
```
✓ "Let's get started"
✓ "Oops! Something went wrong"
✓ "Great! Your changes are saved"
✗ "Error 502: Bad Gateway"
✗ "Invalid input value"
```
