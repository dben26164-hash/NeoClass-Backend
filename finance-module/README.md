# NeoClass Finance Module

Ce module centralise l'ERP financier scolaire.

Contenu prévu :

- Revenus, inscriptions, réinscriptions
- Mensualités, cantine, transport, uniformes
- Dépenses, salaires, charges, fournitures
- Comptabilité générale, journal, grand livre
- Bilan simplifié et rapports financiers

Le schéma Prisma complet est disponible dans `../schema.prisma`.
