# NeoAI Pédagogique

Ce module regroupe les entités d'analyse de cours et les assistants pédagogiques.

Fonctions :

- Lecture de cours et extraction des notions clés
- Génération automatique de résumés, flashcards, quiz, exercices
- Analyse des élèves, détection des difficultés, retards et faiblesses
- Score de maîtrise, niveau de compréhension, plan personnalisé
- Assistant IA contextuel basé uniquement sur le contenu pédagogique de l'école

Le schéma Prisma complet est disponible dans `../schema.prisma`.
